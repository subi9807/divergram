- 점검일: 2026-08-05
- 대상: `adm/`, `api/server/routes/`, 운영 DB 스키마

## 2. API 또는 컴포넌트는 있지만 페이지가 연결되지 않은 항목

### P0. 리조트 가격 관리

- 현재 기반: `/api/admin/resort-prices` CRUD와 `ResortPricingSection.jsx`가 존재한다.
- 문제: 현재 리조트 상세 일부 가격 흐름은 브라우저 저장소와 혼용되어 다중 관리자·다중 기기에서 데이터 불일치 가능성이 있다.
- 필요한 페이지:
  - 리조트별 가격 상품 목록
  - 통화·상품 유형·노출 기간 필터
  - 등록·수정·삭제·노출 중지
  - 서버 DB 단일 저장소 전환

### P0. 디바이스 토큰·푸시 수신 상태

- 현재 기반: `app_device_tokens`, 푸시 발송·이력 API가 존재한다.
- 문제: 회원별 활성 토큰, 플랫폼, 마지막 갱신일, 실패 토큰을 관리자에서 확인할 수 없다.
- 필요한 페이지:
  - iOS/Android 토큰 현황
  - 회원별 등록 기기 조회
  - 만료·실패 토큰 비활성화
  - 푸시 성공·실패·열람률 요약

### P0. 사용자 약관 동의 이력

- 현재 기반: `app_user_consents`와 약관 게시 기능이 존재한다.
- 문제: 회원별 동의 버전과 동의 시점을 관리자에서 증빙할 수 없다.
- 필요한 페이지:
  - 회원·약관 종류·버전 검색
  - 동의/철회 일시와 접속 환경 확인
  - 규제 대응용 CSV 내보내기

### P1. 통신·알림 기본 설정

- 현재 기반: `/api/admin/communication-settings` 조회·수정 API가 존재한다.
- 문제: API를 사용하는 관리자 페이지가 없다.
- 필요한 페이지:
  - 기본 발신자명과 문의 채널
  - 푸시·이메일 채널 활성 상태
  - 기본 딥링크와 운영 문구
  - 변경 이력 기록

### P1. 백그라운드 작업 관리

- 현재 기반: `/api/admin/jobs`, `/api/admin/jobs/dispatch`, `app_jobs`가 존재한다.
- 문제: 예약·실행·실패 작업을 확인하거나 재실행할 화면이 없다.
- 필요한 페이지:
  - 대기·실행·완료·실패 작업 목록
  - 실패 사유와 실행 시간
  - 안전한 재실행과 취소

### P2. DB 조회·데이터 유지보수

- 현재 기반: `/api/admin/tables`, `/api/admin/table/:name`, `TablesSection.jsx`가 존재한다.
- 문제: 라우팅되지 않았으며 seed·migration 기능이 일반 운영 화면과 분리되지 않았다.
- 필요한 페이지:
  - 읽기 전용 테이블 현황
  - 제한된 샘플 조회
  - 데이터 마이그레이션은 최고 관리자만 실행
  - 실행 전 확인 문구와 감사 로그 필수

## 3. 데이터는 있지만 관리자 API와 페이지가 부족한 항목

### P0. 댓글 운영

- 데이터: `app_comments`
- 필요한 기능: 댓글 검색, 신고 연결, 숨김·삭제, 작성자 제재, 일괄 처리.

### P0. 채팅·DM 안전 관리

- 데이터: `app_rooms`, `app_participants`, `app_messages`, `app_message_deliveries`
- 필요한 기능: 신고된 대화만 제한 조회, 메시지 신고 처리, 참여자 제재, 개인정보 접근 감사 기록.
- 주의: 관리자가 모든 대화를 임의 열람하지 않도록 신고 기반 접근 통제가 필요하다.

### P0. 알림 발송·수신 이력

- 데이터: `app_notifications`, 푸시 발송 이력
- 필요한 기능: 대상·유형·전송 상태·읽음 상태 검색, 실패 원인, 딥링크 검증, 재발송.

### P1. 다이빙 로그 운영

- 데이터: `app_records`와 앱 다이빙 로그 기능
- 필요한 기능: 로그 검색, 비정상 수치 탐지, 신고 처리, 첨부 미디어 확인, 삭제 이력.

### P1. 미디어 저장소 관리

- 데이터: `app_post_media`, 로컬 업로드 디렉터리, Cloudinary 업로드 API
- 필요한 기능: 미사용 파일 탐지, 파일 크기·형식·소유자 조회, 삭제 대기, 저장소 사용량, 깨진 URL 점검.

### P1. 포인트 지도 편집

- 현재 상태: 조회만 가능하다.
- 필요한 기능: 포인트 등록·수정·비활성화, 좌표 검증, 중복 포인트 병합, 사진과 설명 관리.

### P1. 스템프·업적 관리

- 현재 상태: 앱 UI는 있으나 관리자용 정의·조건·아이콘·활성 상태 관리 페이지가 없다.
- 필요한 기능: 스템프 CRUD, 달성 조건, 노출 순서, 아이콘, 소급 지급, 지급 이력.

### P2. 팔로우·좋아요 운영 분석

- 데이터: `app_follows`, `app_likes`, `app_saved_posts`
- 필요한 기능: 비정상 활동 탐지, 인기 콘텐츠, 급격한 팔로우 증가, 어뷰징 계정 확인.

## 4. 정식 운영을 위해 새로 필요한 페이지

### P0. 운영 알림·장애 센터

- API, DB, 푸시, 미디어 저장소 상태
- 최근 오류와 실패 작업
- 장애 공지 작성
- 긴급 기능 중지 스위치

### P0. 관리자 계정·권한 관리

- 현재 허용 이메일 환경변수 방식에서 DB 기반 역할 관리로 전환
- 최고 관리자, 운영자, 콘텐츠 검수자, 고객지원 역할 구분
- 메뉴·API 권한 분리와 로그인 이력

### P1. 앱 버전·배포 정책

- iOS/Android 최신 버전과 빌드 번호
- 최소 지원 버전
- 강제 업데이트 여부
- 스토어 링크와 점검 공지

### P1. 고객 문의 관리

- 문의 접수, 담당자 배정, 상태, 답변 이력
- 회원·게시물·결제·리조트 정보 연결

### P1. 운영 분석 리포트

- DAU/MAU, 가입·탈퇴, 게시물·릴스, 신고 처리 시간
- 리텐션과 플랫폼별 사용량
- 기간 비교와 CSV 내보내기

### P2. 후원·결제 운영

- PayPal 후원 내역, 환불·취소, 통화, 회원 연결
- 결제 데이터를 서버에서 직접 보관하지 않는 경우 PayPal 거래 참조 ID만 저장

## 5. 권장 개발 순서

1. 리조트 가격을 서버 DB 단일 저장소로 전환하고 관리 페이지 연결
2. 디바이스 토큰·알림 발송 상태 페이지 개발
3. 사용자 약관 동의 이력 페이지 개발
4. 댓글 및 신고된 채팅 안전 관리 개발
5. 관리자 계정·역할·권한 관리 개발
6. 운영 장애 센터와 백그라운드 작업 페이지 개발
7. 포인트 지도 편집과 미디어 저장소 관리 개발
8. 다이빙 로그, 스템프, 앱 버전 정책 개발
9. 고객 문의, 운영 분석, 후원 거래 관리 개발

## 6. 메뉴 추가 권장안

| 1차 메뉴 | 추가할 2차 페이지 |
| --- | --- |
| 회원 운영 | 약관 동의 이력, 디바이스 관리 |
| 콘텐츠·안전 | 댓글 관리, 신고 채팅, 다이빙 로그, 미디어 저장소, 포인트 편집 |
| 파트너·수익 | 리조트 가격, 후원·결제 |
| 고객 커뮤니케이션 | 알림 이력, 통신 설정, 고객 문의 |
| 시스템 관리 | 운영 상태, 작업 관리, 앱 버전, 관리자 권한, 데이터 조회 |
| 성장·분석 | 운영 분석, 팔로우·좋아요 분석, 스템프 관리 |

미구현 메뉴는 빈 화면으로 먼저 노출하지 않고, API와 권한 검증이 완료된 순서대로 메뉴에 추가한다.
