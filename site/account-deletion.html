Divergram 계정 삭제 안내

앱에서 계정 삭제를 요청할 수 있으며, 탈퇴 후 30일 이내에는 다시 로그인하여 계정을 복구할 수 있습니다.

계정 삭제 요청앱 설정에서 본인이 직접 요청할 수 있습니다.
30일 복구유예기간 내 로그인하고 복구 버튼을 누르면 탈퇴를 철회합니다.
데이터 보호법정 보관 대상은 접근이 제한된 별도 영역에서 관리합니다.

앱에서 요청하는 방법

  1. Divergram에 로그인합니다.
  2. 오른쪽 상단 전체 메뉴에서 설정을 선택합니다.
  3. 계정 관리 → 계정 삭제로 이동합니다.
  4. 삭제 요청일과 복구 가능 마지막 날짜를 확인하고 삭제를 요청합니다.
30일 복구 기간
삭제 요청 직후 계정은 비활성화됩니다. 요청일로부터 30일 이내에 다시 로그인하면 계정 복구 화면으로 이동합니다. 복구 버튼을 누르면 탈퇴가 철회되며, 복구 전에는 다른 앱 기능을 이용할 수 없습니다.

삭제되는 정보

  • 계정, 프로필 및 SNS 로그인 연결 정보
  • 푸시 토큰, 개인정보 및 사용자 환경설정
  • 다이빙 로그, 라이선스와 사용자가 입력한 관련 정보
  • 게시물, 릴스, 댓글 및 업로드한 사진·영상

다른 이용자의 권리 보호, 분쟁 대응 또는 관계 법령 준수를 위해 보존이 필요한 기록은 법정 기간 동안 별도 보관된 후 파기될 수 있습니다. 백업 데이터는 운영 중인 백업 순환 주기에 따라 만료됩니다.

계정을 유지하면서 데이터만 삭제하기

  • 프로필 사진과 소개: 프로필 → 프로필 편집
  • 게시물과 릴스: 해당 콘텐츠의 더보기 → 삭제
  • 다이빙 로그: 프로필 → 총 다이빙 → 로그 선택 → 삭제
  • 알림과 환경설정: 전체 메뉴 → 알림 또는 설정

앱에서 직접 삭제할 수 없는 특정 데이터의 삭제를 요청하려면 아래 고객지원 주소로 데이터 종류와 가입 이메일을 보내 주세요. 본인 확인 후 처리 결과를 안내합니다.

앱에 로그인할 수 없나요?

가입한 이메일 주소, 로그인 제공자와 삭제 요청 사유를 포함하여 고객지원으로 요청해 주세요. 본인 확인 후 삭제 절차를 안내합니다.
