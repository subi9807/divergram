# Divergram Documents

사업계획서, 제안서, 발표 자료 등 대외 문서를 앱/웹 소스와 분리해 관리합니다.

## 문서 목록

- `divergram-business-plan-3page.html`: 「2026년 창업진흥원 정책 아이디어 공모전」 창업 분야 제출용으로 구성한 Divergram 소개·필요성·주요 기능 A4 가로 3장 제안서

## 사용 방법

HTML 파일을 브라우저에서 열어 확인합니다. PDF로 저장할 때는 인쇄 설정에서 다음 값을 사용합니다.

- 용지: A4
- 방향: 가로
- 여백: 없음
- 배율: 100%
- 배경 그래픽: 켬
